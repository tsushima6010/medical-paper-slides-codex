# 医学論文の読み取りと要約

## 目次

- 抽出する情報
- 研究デザイン別の優先事項
- 統計表現
- 研究目的の見せ方
- 限定表現
- スライドへ残す優先順位
- 重要点に絞った考察
- 結論と限界の分離

## 抽出する情報

最初に次を構造化する。

- 書誌情報：タイトル、筆頭著者、ジャーナル、年、DOI
- 研究背景と未解決点
- 研究目的・仮説
- 研究デザインと施設数
- 対象患者、適格基準、除外基準
- 介入・曝露、比較群
- 主要評価項目、副次評価項目
- 解析集団、追跡期間、欠測
- 主要結果と安全性
- 効果量、95% CI、P値、絶対数、分母
- 多変量解析、感度解析、サブグループ解析
- 臨床的意義、限界、一般化可能性、結論

各情報に原文ページ、表番号、図番号を付ける。

## 研究デザイン別の優先事項

### ランダム化比較試験

- ランダム化、盲検化、割付、解析集団を区別する。
- 主要評価項目、効果量、絶対差、有害事象を優先する。
- ITTとper-protocolを混同しない。

### 観察研究

- コホート、症例対照、横断研究を明記する。
- 曝露とアウトカムの時間関係を確認する。
- 調整因子、残余交絡、選択バイアスを残す。
- 関連を因果として表現しない。

### 診断精度研究

- index test、参照基準、対象スペクトラムを示す。
- 感度、特異度、AUC、尤度比、閾値を対応付ける。
- ROC由来のカットオフを外部検証済みと誤認させない。

### システマティックレビュー・メタ解析

- 検索範囲、研究数、対象数、効果モデル、異質性を示す。
- 統合効果だけでなく95% CIと研究間異質性を残す。
- エビデンスの確実性と出版バイアスを確認する。

### 症例報告

- 症例経過、診断根拠、介入、転帰、学びを中心にする。
- 一般化や治療推奨を過度に広げない。

## 統計表現

- P値だけでなく効果量と方向性を優先する。
- 原文にあれば95% CIを残す。
- パーセントには可能な限り分子・分母を添える。
- HR、OR、RRを相互に置換しない。
- 未調整値と調整値を区別する。
- 中央値と平均値、IQRと範囲を区別する。
- 多変量解析は論文の結論を理解するために必要な因子だけを再構成する。
- 感度解析は頑健性を示す範囲で簡潔にまとめる。

## 研究目的の見せ方

- 目的スライドのキーメッセージは、研究で明らかにしたいことを「〜を明らかにする」「〜を評価する」などの現在形で示す。「調べた」「評価した」「検証した」など、実施済みの作業を述べる過去形で終えない。

- PECOは論文を読み解く内部フレームとして必要に応じて使う。
- 要約スライドでは、P・E・C・Oの略号、4区分、カードを定型表示しない。
- スライド上の見出しは「研究目的」ではなく「目的」、「研究仮説」ではなく「仮説」とする。
- 目的は「関連を評価する」「検証する」という研究者側の作業説明だけで終えず、「曝露・介入が、どの臨床転帰に影響するか」という読み手の疑問が自然に伝わる簡潔な1文にする。
- 観察研究では、目的を平易な疑問として示しても、結果と結論では関連を因果へ言い換えない。
- 目的スライドに対象患者数、施設、測定時期、追跡期間などの方法情報を詰め込まない。これらは対象と方法のスライドへ分離する。
- 目的スライドへ主要評価項目、副次評価項目、探索的評価項目を置かない。これらは対象と方法または解析スライドで区別して示す。
- 目的と仮説は左揃えにし、同じ幅の左右2カラムへ置く。中央揃えの長文を使わない。
- 目的スライドは目的と仮説の2要素だけで完結させ、下段へ解析項目や補足説明を追加しない。
- ユーザーが教育目的でPECO表示を明示的に求めた場合だけ例外とする。

## 限定表現

原文の確実性を維持する。

- exploratory → 「探索的解析で」
- retrospective → 「後方視的に」
- single-center → 「単施設で」
- associated with → 「関連した」
- may / might → 「可能性がある」「なりうる」
- requires validation → 「外部検証が必要」

「示唆した」を「証明した」に変えない。「関連した」を「引き起こした」に変えない。

## スライドへ残す優先順位

1. 主要結果
2. 臨床的意味
3. 効果量と不確実性
4. 研究対象とデザイン
5. 結果解釈に必要な方法
6. 感度解析
7. 限界

論文の章順をそのままスライド順にしない。読み手が問いから結論へ進める順序に再構成する。

## 重要点に絞った考察

- 抄読会での吟味や内容把握に必要な解釈を、原則1枚・1〜2論点に絞る。結果の意味、臨床上の位置づけ、重要な機序のうち、その論文で最も重要なものを選ぶ。
- Discussionの章立てや段落数に合わせて枚数を増やさない。結果の言い換え、二次的な論点、一般論は省き、必要な補足はノートへ移す。
- 直接示された結果と、機序の推測・臨床上の提案を区別する。自明な「著者は提案した」という前置きを繰り返さず、適切な限定語と追跡可能な出典で区別を保つ。
- タイトルには区分名を付けず、論点自体を簡潔に書く。

## 結論と限界の分離

- 最終スライドは、原論文の確実性を保った結論2〜3点だけにする。
- 結論の各箇条書きは必ず1行にし、2行へ折り返さない。収まらない場合は語句を厳選し、箇条書き数を減らす。
- 最後の箇条書きは、その論文が結果をどのように位置づけるかを示す。例として「簡便なリスク層別化指標となりうる」のように、原文の確実性を保った臨床的・研究的スタンスを書く。
- 「外部検証が必要」「さらなる研究が必要」などの付帯的な注意は結論の最後へ足さず、必要なら直前の限界スライドまたはスピーカーノートへ移す。
- 注意書きや限界を結論へ追記しない。
- Limitationsが必要な研究では、独立した直前のスライドで示す。
